What this can and cannot tell you

This deterministic rule pack recognizes documented CPU fallback, partial offload, allocation-error, and Docker/GPU signatures. It separates supplied observations from likely or possible causes. Missing evidence stays “insufficient evidence.”

It never runs a command, changes your configuration, measures performance, or promises a repair. Use the linked official documentation to make any system change deliberately.
